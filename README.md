# Distance-Calculator

## Description

This program calculates the distance between two points (x1, y1) and (x2, y2) on a 2D plane

using input values and a math library.

## How to Run

1. Open the program file in PyCharm.

2. Run the program.

3. Enter the value for kilometer.

4. Check the distance for miles displayed on the screen.

5. It asks if we want to convert another number:

   Typing yes:
6. Enter the value for new_kilometer

7. Check the distance for miles displayed on screen

8. It should also print "Program ended."

   Typing no:
6. "Program ended" should display on screen.
   
## Input Needed

- kilometer

- new_kilometer (if yes was entered)

## Sample Output

Yes situation:
Enter the distance in kilometers: 123
The distance in miles 76.428633
Do you want to convert another distance (yes/no): yes
Enter the distance in kilometers: 456
The distance in miles is: 283.345176
Program ended.

No situation:
Enter the distance in kilometers: 123
The distance in miles 76.428633
Do you want to convert another distance (yes/no): no
Program ended.

The distance between the two points is: 7.07
